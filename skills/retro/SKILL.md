# Retro
Inspect the observed friction, distinguish a local execution mistake from a reusable workflow defect, and fix the smallest cause within the authorized scope. Prefer deleting a wrong rule, correcting a boundary or merging duplicates over adding process.

A session ending is not a reason to edit global instructions. When changes to workflow/global files were not requested, propose the specific change; do not silently apply it. Recheck that the fix does not add unrelated reading, approval rounds or maintenance. No lessons journal is required.

Report observed problem, cause, smallest fix and validation. If no workflow change is justified, say so and stop.
